# EvaluacionDeBilletesConProcesamientoDigitalDeSe-alesPDS2
Sistema forense híbrido para la autenticación de papel moneda peruano. Combina Deep Learning (EfficientNet-B0) para enrutamiento semántico y Procesamiento Digital de Señales (PDS 2D) estricto. Audita relieves (Intaglio), frecuencias y texturas algodonadas mediante 19 firmas matemáticas anti-falsificación.
